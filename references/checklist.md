# SEO/GEO Audit Checklist

## Step 3 — On-Page SEO
- [ ] Title: 50-60 chars, includes `[brand] distributor`
- [ ] Meta description: 150-160 chars, includes CTA
- [ ] H1: exactly one, matches brand name
- [ ] Canonical URL: `https://www.core-distributor.com/[brand]/`
- [ ] OG tags: og:title, og:description, og:image, og:url present
- [ ] JSON-LD schema: Organization, Product, BreadcrumbList, TechArticle, NewsArticle
- [ ] Keyword density: 1-2% in body text
- [ ] Image alt attributes: all images have descriptive alt text
- [ ] Internal links: at least 3 per page
- [ ] External links: working, no broken links

## Step 3 — Technical SEO
- [ ] robots.txt: allows AI crawlers (ClaudeBot, GPTBot, Google-Extended) or explicitly blocks
- [ ] Sitemap.xml: includes all brand pages, excludes internal-only pages
- [ ] HTTPS: valid SSL certificate, no mixed content
- [ ] 404 check: sample internal links return 200
- [ ] Core Web Vitals: LCP < 2.5s, FID < 100ms, CLS < 0.1
- [ ] Mobile: responsive design, no horizontal scroll
- [ ] Security: no internal directories exposed (check .project-memory/ etc.)

## Step 4 — Content Quality (CORE-EEAT)
- [ ] Content: accurate, complete technical specifications
- [ ] Optimization: keywords naturally integrated
- [ ] Readability: clear language, well-structured
- [ ] Engagement: FAE insights, customer cases present
- [ ] Authority: manufacturer/distributor relationships cited
- [ ] Trust: contact info, privacy policy, terms present

## Step 4 — Domain Authority (CITE)
- [ ] Citations: brand mentioned on other authoritative sites
- [ ] Influence: social presence, industry recognition
- [ ] Trust Signals: SSL, HTTPS, consistent NAP
- [ ] Engagement: user interaction, comments, shares
